# NAVLLM · 面向 6G 边缘网络实时任务的自适应内生智能体

**[打开网页演示](https://forece-ui.github.io/NAVLLM/)**

在输电线路无人机巡检中，远程专家需要及时看清现场细节，但回传带宽会随飞行位置和现场条件变化。码率过高容易卡顿，码率过低又会丢失核查所需的细节。NAVLLM 在边缘侧读取网络与业务状态，直接生成可执行的网络动作，并通过运行反馈持续调整后续决策。

这是华中科技大学电子信息与通信学院面向 2026 年度「挑战杯」揭榜挂帅擂台赛的项目。整体方案在视口预测（VP）、自适应码率控制（ABR）和作业调度（CJS）三类任务上开展评估。本仓库包含 **ABR 训练与评估代码、视频回传系统，以及 NAVLLM、BBA 和 MPC 的三路对比控制台**。

## 技术路线

1. **多源状态编码。** 针对链路时序、图像、作业依赖图和结构化数值使用相应的编码器，再通过线性投影和层归一化形成统一维度的嵌入序列，送入预训练模型。ABR 决策使用历史吞吐量、下载耗时、缓冲和候选分片大小等状态。
2. **任务专用输出头。** 从模型输出特征直接得到预测值或控制动作。视口预测回归方向角，ABR 从预设的六档码率中选择下一分片的档位，作业调度输出阶段选择和资源分配决策。
3. **离线经验驱动的低秩适配。** 三类任务共享预训练基座，并分别用监督数据或离线决策经验进行适配。训练时冻结主干权重，更新编码器、LoRA 参数和任务输出头。项目评测采用 Llama2-7B，ABR 的 LoRA 秩设为 128。

## ABR 实物回传系统

无人机通过原生图传把巡检视频送到地面端。地面端接入视频后进行编码和分片，边缘侧根据链路历史和缓冲状态选择下一分片的码率，发送端在分片边界执行该决策。每个分片传输完成后，系统更新吞吐量和缓冲等状态，并记录该分片的决策和传输结果。

| 系统角色 | 工作内容 |
| --- | --- |
| 终端感知智能体 | 接入视频，编码并发送分片，执行码率指令，反馈分片传输状态 |
| 网络智能体 | 根据传输状态从 300、750、1200、1850、2850、4300 kbps 中选出下一分片的码率 |
| 运维智能体 | 对照三路视频与网络状态，查看决策日志及码率、卡顿和 Reward 等指标 |

## 实验验证

下表汇总项目汇报中的对标结果。三类任务均评估了单项条件变化和联合变化，覆盖轨迹与预测窗口、网络与视频、资源与请求量。

| 验证任务 | 对标方法 | 项目汇报结果 |
| --- | --- | --- |
| 视口预测（VP） | TRACK | 平均角度误差降低 20.5% |
| 自适应码率控制（ABR） | GENET | QoE 提升 14.8% |
| 作业调度（CJS） | Decima | 作业完成时间缩短 11.1% |
| ABR 实物视频回传 | MPC | 平均 QoE 提升 15.4%，累计卡顿降低 80.1% |

ABR 仿真采用 Envivio-Dash3 视频和 FCC 带宽轨迹。项目的消融实验还对照了从头训练、关闭低秩适配和完整模型三种配置，评估预训练与任务适配对三类任务的影响。

ABR 对比采用统一的 QoE 口径。单片得分由码率收益减去卡顿惩罚与切换惩罚得到，平均 QoE 是各分片得分的平均值。码率以 Mbps 计，卡顿以秒计，卡顿和切换的惩罚系数分别为 4.3 和 1。

## 网页控制台

- **当前数据**显示吞吐、码率与缓冲曲线，并提供分片明细、模型输入状态和三种算法的性能汇总。
- **视频对比**并排显示 NAVLLM、BBA 和 MPC 的播放器与运行日志。
- **实验结果**在线展示示例汇总，本地控制台可嵌入独立图表服务，默认端口为 `5173`。

GitHub Pages 使用示例遥测和一段共用动画展示界面。下载仓库后也可以直接打开 `index.html` 查看。实时收流和接收端控制通过本地 Python 服务运行。

## 本地运行 ABR 实验

1. 在仓库根目录启动控制台，然后访问 [本地控制台](http://127.0.0.1:8088/)。

   ```sh
   python web_controller.py --host 127.0.0.1 --port 8088
   ```

2. 准备与模型兼容的 PyTorch、Transformers、NumPy、Munch 等依赖，按控制台表单填写 NAVLLM 模型目录和经验池路径，再点击「启动三路接收」。模型权重、经验池和原始视频需自行准备。
3. 在发送端安装 FFmpeg 和 ffprobe，然后发送一段本地 MP4。下例使用本机和默认三路端口，可按实验网络调整。

   ```sh
   python video_sender.py --input example.mp4 --server-host 127.0.0.1 --ports 5001 5002 5003 --limit-mbps 0
   ```

| 代码入口 | 用途 |
| --- | --- |
| [`video_sender.py`](video_sender.py) | 六档视频编码与分片，执行接收端决策 |
| [`abr_receiver.py`](abr_receiver.py) | NAVLLM、BBA、MPC 决策和接收状态更新 |
| [`web_controller.py`](web_controller.py) / [`index.html`](index.html) | 接收进程管理、HLS 播放和网页控制台 |
| [`generate_exp_pool.py`](generate_exp_pool.py) / [`run_plm.py`](run_plm.py) / [`run_baseline.py`](run_baseline.py) | 经验池生成、模型训练与评估、ABR 基线运行 |
| [`network_trace_tools/`](network_trace_tools/) | 带宽轨迹探测与限速测试 |
